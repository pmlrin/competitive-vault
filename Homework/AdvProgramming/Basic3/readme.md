### 基础实验题目

#### 一、目标与要求
本实验的主要目标是熟练掌握C++面向对象编程中的继承与派生机制，包括单重继承、多重继承、虚继承等概念。实验要求实现四个部分的内容：

1. 阅读并调试单重继承程序，理解构造函数和析构函数的调用顺序。
2. 阅读并调试多重继承程序，掌握作用域分辨符的使用和二义性问题的解决。
3. 定义Person类及其派生类Teacher、Cadre和TeacherCadre，实现多重继承并使用虚继承避免二义性。
4. 定义Staff类及其派生类Saleman、Manager和SaleManager，实现员工工资管理系统，使用虚继承处理多重继承问题。

每个部分都需要编写完整的C++代码，并确保程序能正确编译和运行。

#### 二、工具/准备工作
在开始实验前，应回顾C++面向对象编程的基础知识，包括类与对象的定义、继承与派生的概念、构造函数与析构函数、多重继承的二义性问题以及虚继承的解决方法。

需要的硬件设施：一台安装有Windows操作系统的计算机。

需要安装的C++集成开发环境软件：Visual Studio Code (VS Code) 或其他C++ IDE，如Visual Studio。确保安装了C++编译器，如MinGW的g++。

#### 三、实验分析
1. **1.cpp**：该程序演示了单重继承的构造函数和析构函数调用顺序。类A是基类，类B继承A，类C继承B。当创建C对象时，先调用基类构造函数，再调用派生类构造函数；销毁时相反。算法简单，无需复杂设计。

2. **2.cpp**：该程序展示了多重继承中的二义性问题。类C同时继承A和B，A和B都有show()方法，通过作用域分辨符A::show()和B::Show()来区分。类结构使用protected继承，确保数据成员在派生类中可见。

3. **3.cpp**：定义了Person基类，包含姓名、年龄、性别。Teacher和Cadre虚继承Person，添加职称和职务。TeacherCadre多重继承Teacher和Cadre，使用虚继承避免Person成员的二义性。showInfo()方法使用虚函数实现多态。

4. **4.cpp**：Staff基类包含员工基本信息，使用静态成员count生成编号。Saleman和Manager虚继承Staff，添加销售相关数据。SaleManager多重继承Saleman和Manager。Input()和Output()方法用于数据输入输出，OutputWage()计算工资。使用菜单循环实现交互。

#### 四、实验代码
1. **1.cpp**：直接编写类定义和main函数，创建C对象观察输出。
2. **2.cpp**：编写类定义，注意A的show()和B的Show()的区别，使用作用域分辨符调用。
3. **3.cpp**：定义Person类及其派生类，使用virtual public继承。构造函数初始化列表正确初始化基类和成员。main中创建TeacherCadre对象并调用showInfo()。
4. **4.cpp**：定义Staff类，静态成员初始化。派生类使用virtual public。Input()方法先调用基类Input()，然后输入特有数据。main中使用while循环和switch实现菜单选择。

#### 五、测试与结论
1. **1.cpp**：运行程序，输出构造A、构造B、构造C、析构C、析构B、析构A。符合继承顺序。
2. **2.cpp**：运行程序，输出5,18、5、18。正确处理多重继承。
3. **3.cpp**：运行程序，输出Name:张三, Age:30, Sex:男、Title:教授、Post:主任、Wages:5000。虚继承正确避免二义性。
4. **4.cpp**：运行程序，选择不同类型员工，输入数据，输出信息和工资计算。覆盖所有继承情况。

所有程序编译通过，运行结果正确，满足实验目标与要求。

#### 六、实验总结
本实验通过继承与派生展示了面向对象编程的强大功能。算法特点是利用继承复用代码，虚继承解决多重继承问题。我进行了功能扩展，如在4.cpp中添加菜单循环实现交互输入。创新部分在于正确使用虚继承避免二义性。最有价值的内容是理解构造函数初始化顺序和作用域分辨符的使用。需要进一步了解虚函数和多态的深入应用。编程感悟：继承使代码更模块化，但需注意二义性问题。
