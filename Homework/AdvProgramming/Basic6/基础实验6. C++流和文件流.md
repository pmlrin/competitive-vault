## 三、实验分析

### 任务1：九九乘法表格式化输出

**算法分析**

使用嵌套循环实现九九乘法表。外层循环i从1到9表示行号，内层循环j从1到9表示列号。为了实现上三角形式，当j < i时输出空白，当j >= i时输出乘积i*j。每个数值使用setw(6)控制宽度，实现右对齐。

**关键技术**

- setw(n)函数设置输出宽度为n个字符
- 默认右对齐方式显示数据
- 嵌套循环的条件设置

### 任务2：进制转换输出

**算法分析**

利用流的内部状态标志控制输出进制。通过setf()函数设置各种进制标志（ios::dec、ios::oct、ios::hex），通过unsetf()清除旧标志。ios::showbase标志用于显示进制前缀。

**关键技术**

- ios::dec、ios::oct、ios::hex进制标志
- ios::showbase显示进制前缀
- setf()和unsetf()的配合使用

### 任务3：文件读写操作

**算法分析**

文件操作分为两个阶段。写入阶段：创建ofstream对象、打开文件、检查状态、写入数据、关闭文件。读取阶段：创建ifstream对象、打开文件、检查状态、使用getline()逐行读取、关闭文件。getline()自动去除换行符，eof()用于判断文件末尾。

**关键技术**

- ofstream和ifstream的使用
- is_open()检查文件打开状态
- getline()逐行读取文本
- eof()判断文件末尾

### 任务4：复数类与运算符重载

**类结构设计**

```cpp
class Complex {
private:
    double realPart;   // 实部
    double imagPart;   // 虚部
public:
    Complex(double r=0, double i=0);
    double GetRealPart() const;
    double GetImagPart() const;
    friend ostream& operator<<(ostream&, const Complex&);
};
```

**算法原理**

重载operator<<实现复数的格式化输出。根据虚部的正负性采用不同的输出格式：虚部为正时输出"a+bi"，虚部为负时输出"a-bi"，虚部为零时仅输出实部。

### 任务5：学生管理系统

系统包含两个核心类：Student类管理学生数据，提供二进制序列化接口；StudentManage类实现系统业务逻辑，提供交互式菜单。

**数据存储结构**

## 四、实验代码

### 任务1：九九乘法表 (1.cpp)

程序使用两层嵌套循环输出9×9矩阵形式的乘法表。外层循环控制行号，内层循环遍历所有列。当列号小于行号时输出空白，否则输出乘积。使用setw(6)控制每个数字占用6个字符宽度，实现整齐对齐。

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    // 输出列标
    cout << setw(6) << " ";
    for (int j = 1; j <= 9; j++) {
        cout << setw(6) << j << "*";
    }
    cout << endl << endl;

    // 输出乘法表上三角
    for (int i = 1; i <= 9; i++) {
        cout << setw(6) << i << "*";
        for (int j = 1; j <= 9; j++) {
            if (j >= i) {
                cout << setw(6) << i * j;
            } else {
                cout << setw(6) << " ";
            }
        }
        cout << endl;
    }

    return 0;
}
```
